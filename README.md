I recently created an interactive Sales Dashboard in Excel to analyze sales performance, customer behavior, and profit trends from a retail dataset.
📌 Problem Statement:
Businesses often struggle to understand large amounts of sales data and identify important patterns that can help improve decision-making.
The objective of this project was to transform raw sales data into an interactive dashboard that provides clear insights into:
• Sales performance
• Profit trends
• Customer contribution
• Category-wise analysis
• Regional sales distribution

🛠 Tools & Features Used:
✅ Excel
✅ Pivot Tables
✅ Pivot Charts
✅ Slicers & Filters
✅ Data Cleaning
✅ Interactive Dashboard Design

📊 Key Insights:
• Technology category generated strong profit growth over the years
• Monthly sales showed an overall upward trend
• A few top customers contributed a major share of profits
• Customer count increased consistently year by year
• Sales performance varied across different states

📚 What I Learned:
This project helped me improve my skills in data cleaning, visualization, dashboard creation, and generating business insights from raw data.
